# Module 09: Daily Sales Report

## UI Requirement

All screens within this module shall follow the UI standards in:

```text
00-ui-architecture.md
```

Use Laravel Blade + Bootstrap 5 only. Do not use React, Vue, Svelte, Livewire, InertiaJS, or SPA architecture.

---


## Objective
Provide clear daily sales visibility for management.

## Report Filters

- Date
- Date range
- Cashier
- Payment method
- Sale type

## KPI Summary

- Total revenue
- Membership sales
- Product sales
- Walk-in sales
- Cash collection
- Bank transfer collection
- QR collection
- Number of transactions

## Report Sections

### Sales Breakdown
- Membership
- Product
- Walk-in

### Payment Breakdown
- Cash
- Bank transfer
- QR
- Other

### Transaction List
Show:

- Time
- Receipt number
- Type
- Description
- Payment method
- Amount
- Received by

## Export

- XLSX only
- PDF export is intentionally out of scope unless approved later.

## Suggested Database Tables Used

- sales
- sale_items
- payments
- users
- members
- products

## Acceptance Criteria

- Report can be generated by date.
- Totals match POS transactions.
- Payment breakdown is accurate.
- Report can be exported.
- Manager and admin can view all reports.
- Cashier can view own sales only, if permission enabled.
